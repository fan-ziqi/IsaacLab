生成多个资产#

典型的生成配置（见 生成基本物体到场景中 教程）会将同一个资产复制到表达式解析出的所有 prim 路径。多资产工作流满足两种相关的组合需求：

  1. 刚性物体集合将每个环境中的多个刚性物体批量组织起来，通过统一的数据和命令 API 访问。

  2. 多资产生成器为一个场景资产绑定声明多个变体，使不同环境可包含不同几何体或机器人变体。

本指南演示这两种机制，并解释它们在 PhysX 和 Newton 中的执行差异。

打包提供的 multi-asset 示例包含参考脚本 multi_asset.py 。

169def run_simulator(sim: sim_utils.SimulationContext, scene: InteractiveScene):
170    """Runs the simulation loop."""
171    # Extract scene entities
172    # note: we only do this here for readability.
173    rigid_object: RigidObject = scene["object"]
174    rigid_object_collection: RigidObjectCollection = scene["object_collection"]
175    robot: Articulation = scene["robot"]
176    # Define simulation stepping
177    sim_dt = sim.get_physics_dt()
178    count = 0
179    step_count = 0
180    # Step while a visualizer window is still open (or none exist, e.g. headless); works for kit and newton.
181    while sim.is_running() and (args_cli.max_steps < 0 or step_count < args_cli.max_steps):
182        # Reset
183        if count % 250 == 0:
184            # reset counter
185            count = 0
186            # reset the scene entities
187            # object
188            root_pose = rigid_object.data.default_root_pose.torch.clone()
189            root_pose[:, :3] += scene.env_origins
190            rigid_object.write_root_pose_to_sim_index(root_pose=root_pose)
191            root_vel = rigid_object.data.default_root_vel.torch.clone()
192            rigid_object.write_root_velocity_to_sim_index(root_velocity=root_vel)
193            # object collection
194            default_pose_w = rigid_object_collection.data.default_body_pose.torch.clone()
195            default_pose_w[..., :3] += scene.env_origins.unsqueeze(1)
196            rigid_object_collection.write_body_pose_to_sim_index(body_poses=default_pose_w)
197            default_vel_w = rigid_object_collection.data.default_body_vel.torch.clone()
198            rigid_object_collection.write_body_com_velocity_to_sim_index(body_velocities=default_vel_w)
199            # robot
200            # -- root state
201            root_pose = robot.data.default_root_pose.torch.clone()
202            root_pose[:, :3] += scene.env_origins
203            robot.write_root_pose_to_sim_index(root_pose=root_pose)
204            root_vel = robot.data.default_root_vel.torch
205            robot.write_root_velocity_to_sim_index(root_velocity=root_vel)
206            # -- joint state
207            joint_pos = robot.data.default_joint_pos.torch
208            joint_vel = robot.data.default_joint_vel.torch
209            robot.write_joint_position_to_sim_index(position=joint_pos)
210            robot.write_joint_velocity_to_sim_index(velocity=joint_vel)
211            # clear internal buffers
212            scene.reset()
213            print("[INFO]: Resetting scene state...")
214
215        # Apply action to robot
216        robot.set_joint_position_target_index(target=robot.data.default_joint_pos.torch)
217        # Write data to sim
218        scene.write_data_to_sim()
219        # Perform step
220        sim.step()
221        step_count += 1
222        # Increment counter
223        count += 1
224        # Update buffers
225        scene.update(sim_dt)
226

229    """Main function."""
230    with launch_simulation(cfg=PhysicsCfg(), launcher_args=args_cli) as physics_cfg:
231        sim_cfg = sim_utils.SimulationCfg(dt=0.005, device=args_cli.device, physics=physics_cfg)
232        sim = sim_utils.SimulationContext(sim_cfg)
233        # Set main camera
234        sim.set_camera_view([2.5, 0.0, 4.0], [0.0, 0.0, 2.0])
235
236        # Design scene
237        scene_cfg = MultiObjectSceneCfg(num_envs=args_cli.num_envs, env_spacing=2.0, replicate_physics=True)
238        if args_cli.physics == "newton_mjwarp":
239            # Newton views currently require a uniform body layout across worlds.
240            scene_cfg.object.spawn.assets_cfg = scene_cfg.object.spawn.assets_cfg[1:2]
241            scene_cfg.robot.spawn.usd_path = scene_cfg.robot.spawn.usd_path[0]
242        with Timer("[INFO] Time to create scene: "):
243            scene = instantiate(scene_cfg)

245        sim.reset()
246        print("[INFO]: Setup complete...")
247        run_simulator(sim, scene)

刚性物体集合#

如果每个环境都包含同一组独立运动的刚体，且希望以一个批次访问它们，可使用刚性物体集合。集合以 (env, object, ...) 布局提供数据，并接受 (env_ids, obj_ids) 选择来执行命令。与分别管理各物体相比，集合只使用一个批量物理视图。

object_collection: RigidObjectCollectionCfg = RigidObjectCollectionCfg(
    rigid_objects={
        "object_A": RigidObjectCfg(
            prim_path="/World/envs/env_.*/Object_A",
            spawn=sim_utils.SphereCfg(radius=0.1, **RED_MATERIAL, **OBJECT_PHYSICS),
            init_state=RigidObjectCfg.InitialStateCfg(pos=(0.0, -0.5, 2.0)),
        ),
        "object_B": RigidObjectCfg(
            prim_path="/World/envs/env_.*/Object_B",
            spawn=sim_utils.CuboidCfg(size=(0.1, 0.1, 0.1), **RED_MATERIAL, **OBJECT_PHYSICS),
            init_state=RigidObjectCfg.InitialStateCfg(pos=(0.0, 0.5, 2.0)),
        ),
        "object_C": RigidObjectCfg(
            prim_path="/World/envs/env_.*/Object_C",
            spawn=sim_utils.CylinderCfg(radius=0.1, height=0.3, **RED_MATERIAL, **OBJECT_PHYSICS),
            init_state=RigidObjectCfg.InitialStateCfg(pos=(0.5, 0.0, 2.0)),
        ),
    }
)

RigidObjectCollectionCfg 配置持有一个由 RigidObjectCfg 实例组成的字典。每个字典键都是对应物体在集合中的稳定标识。

本例通过两个物理后端共用的 API 重置集合中的所有成员：

default_pose_w = rigid_object_collection.data.default_body_pose.torch.clone()
default_pose_w[..., :3] += scene.env_origins.unsqueeze(1)
rigid_object_collection.write_body_pose_to_sim_index(body_poses=default_pose_w)
default_vel_w = rigid_object_collection.data.default_body_vel.torch.clone()
rigid_object_collection.write_body_com_velocity_to_sim_index(body_velocities=default_vel_w)

为一个场景资产生成不同变体#

使用 MultiAssetSpawnerCfg 和 MultiUsdFileCfg ，为一个场景资产绑定声明可用变体。 InteractiveScene 将这些变体纳入克隆计划，并为每个环境分配一个有效的原型组合。

对于通过配置构建的资产，将 MultiAssetSpawnerCfg 赋给 RigidObjectCfg 的生成配置：

object: RigidObjectCfg = RigidObjectCfg(

            sim_utils.SphereCfg(radius=0.3, **BLUE_MATERIAL),

            sim_utils.SphereCfg(radius=0.3, **GOLD_MATERIAL),
            sim_utils.CylinderCfg(radius=0.3, height=0.6, **PURPLE_MATERIAL),
            sim_utils.CuboidCfg(size=(0.3, 0.3, 0.3), **PURPLE_MATERIAL),
            sim_utils.SphereCfg(radius=0.3, **PURPLE_MATERIAL),
        ],
        random_choice=False,
        **OBJECT_PHYSICS,
    ),
    init_state=RigidObjectCfg.InitialStateCfg(pos=(0.0, 0.0, 2.0)),
)

assets_cfg 列表定义克隆计划可用的原型。变体分配由 clone_strategy 控制；默认的 sequential() 策略按轮转顺序分配组合。如果希望随机采样组合，应在构建场景前设置策略：

from isaaclab import cloner

scene_cfg.clone_cfg.clone_strategy = cloner.random

变体兼容性#

同一批量资产接口下的所有变体必须结构兼容。关节体变体必须具有相同的连杆、关节、碰撞刚体数量及名称。刚性物体变体可以有不同的几何和材料，但必须保留兼容的刚体布局。结构不同的资产应建模为独立的场景绑定。

克隆规划与物理复制#

InteractiveScene 将多资产变体表示为克隆计划中的原型，因此可以保持 replicate_physics 开启，只向各原型所分配的环境复制该原型。不要仅因为场景使用多资产生成器，就禁用物理复制。只有无法表示为克隆变体的逐环境舞台差异，才使用 replicate_physics=False ；Newton 后端不支持该模式。

本例保持物理复制开启。对于 Newton，还会将独立物体和关节体分别缩减为一个变体，因为它们的批量 Newton 视图目前要求各世界的刚体布局一致：

scene_cfg = MultiObjectSceneCfg(num_envs=args_cli.num_envs, env_spacing=2.0, replicate_physics=True)
if args_cli.physics == "newton_mjwarp":
    # Newton views currently require a uniform body layout across worlds.
    scene_cfg.object.spawn.assets_cfg = scene_cfg.object.spawn.assets_cfg[1:2]
    scene_cfg.robot.spawn.usd_path = scene_cfg.robot.spawn.usd_path[0]

原型分配与复制的更多细节见 克隆环境 。

运行示例#

物理后端与可视化器分别选择。从仓库根目录运行以下任一命令：

uv run --extra isaacsim isaaclab example multi-asset \
    --physics isaacsim_physx --visualizer kit --num_envs 2048

uv run --extra isaacsim isaaclab example multi-asset \
    --physics newton_mjwarp --visualizer kit --num_envs 2048

uv run isaaclab example multi-asset \
    --physics newton_mjwarp --visualizer newton_gl --num_envs 2048

Newton 命令使用与 PhysX 命令相同的 RigidObjectCollectionCfg 和 (env_ids, obj_ids) API。由于上述布局一致性限制，它们不会演示不同环境的物体或关节体变体；要查看示例的这一部分，请使用 PhysX 命令。运行不依赖 Kit 的命令前，参阅 安装指南 。

关闭窗口或在终端按 Ctrl+C ，即可停止仿真。
