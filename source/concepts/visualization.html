可视化#

Isaac Lab 提供了 5 种可视化器，用于实时查看和调试仿真。渲染器负责生成训练所需的传感器数据，而可视化器则提供快速、轻量的画面反馈，方便人工观察和录制。可视化器也可以通过相机流面板显示同样的传感器数据。

本页介绍：

  • 快速入门 ：通过 --viz 启动可视化器

  • 可视化器概览 ：逐一介绍各个可视化器

  • 共有功能 ：各可视化器的通用功能

  • 使用方法 ：常用命令行参数和配置示例

  • 限制 ：各可视化器的差异和故障排查

五种可视化器运行 Isaac-Velocity-Flat-AnymalD，并使用环形速度指令
绿色箭头表示指令速度；蓝色箭头表示当前速度。

Newton GL
Viser
Newton RTX
Kit
Rerun

注意：Newton RTX 暂不支持可视化标记，因此没有速度箭头。

快速开始#

在任意训练命令中加入 --viz 即可启动可视化器。 --visualizer 是等效的别名。

# Newton GL: lightweight OpenGL viewport
uv run isaaclab train --rl_library rsl_rl --task Isaac-Cartpole --viz newton_gl

# Viser: browser-based viewer
uv run isaaclab train --rl_library rsl_rl --task Isaac-Cartpole --viz viser

# Kit viewport
uv run isaaclab train --rl_library rsl_rl --task Isaac-Cartpole --viz kit

# Multiple visualizers simultaneously (comma-separated, no spaces)
uv run isaaclab train --rl_library rsl_rl --task Isaac-Cartpole --viz rerun,newton_rtx

./isaaclab.sh train --rl_library rsl_rl --task Isaac-Cartpole --viz newton_gl
./isaaclab.sh train --rl_library rsl_rl --task Isaac-Cartpole --viz viser
./isaaclab.sh train --rl_library rsl_rl --task Isaac-Cartpole --viz kit
./isaaclab.sh train --rl_library rsl_rl --task Isaac-Cartpole --viz rerun,newton_rtx

备注

大多数任务默认使用 PhysX 后端，需要安装 Isaac Sim。如果尚未安装，请在上述 uv run 命令中加入 --extra isaacsim ；详情见 可选依赖组 。

备注

train 和 play 仅在传入 --viz 时启动可视化器；内置演示和示例则会打开各自的默认可视化器。--viz none 可以关闭可视化器。

关于组合使用可视化器、无界面运行等常见场景，请参阅下文的 使用方法 。

VisualizerCfg 源代码（共用基类）
@configclass
class VisualizerCfg:
    """Base configuration for all visualizer backends.

    Note:
        This configuration can be used directly as
        :attr:`~isaaclab.sim.SimulationCfg.default_visualizer_cfg` to provide shared defaults.
        To create a visualizer, use a concrete config from ``isaaclab_visualizers``, such as
        ``KitVisualizerCfg`` or ``NewtonGLVisualizerCfg``.
    """

    class_type: type[BaseVisualizer] | str | None = None
    """Visualizer implementation class. Concrete configs must set this field."""

    cloning_contexts: tuple[type | str, ...] = ()
    """Clone contexts that build this visualizer's scene representation from the asset plan."""

    # Primary interactive camera settings
    eye: tuple[float, float, float] = (4.0, -4.0, 3.0)
    """Interactive visualizer camera eye position in world coordinates."""

    lookat: tuple[float, float, float] = (0.0, 0.0, 0.0)
    """Interactive visualizer camera look-at target in world coordinates."""

    focal_length: float = 12.0
    """Camera focal length in millimeters for visualizer camera views."""

    background_color: tuple[float, float, float] | None = (0.30, 0.55, 0.82)
    """Solid background color as normalized RGB values in ``[0, 1]``.

    Kit, Newton GL, and Newton RTX honor this field. Set it to ``None`` to preserve the
    backend's native background. Scene lighting remains independent of the visible background.
    """

    # ── Streaming view ────────────────────────────────────────────────────────
    # Captures pixels from a camera sensor (existing or auto-created), tiles them
    # across envs and GT types, and shows the result as an image panel in interactive
    # visualizers (Newton GL, Kit) or pushes it per-step to sink-based ones (Rerun, Viser).

    streaming_view: bool = False
    """Enable the streaming camera image view (opt-in, disabled by default)."""

    # Source — existing sensor (takes priority when set)
    streaming_sensor_prim_path: str | None = None
    """Prim path of an existing TiledCamera sensor to stream from.

    When set, all ``streaming_cam_*`` fields are ignored.  Should point to an
    existing camera sensor, e.g. ``"/World/envs/*/Camera"``.
    """

    # Source — auto-created camera (used when streaming_sensor_prim_path is None)
    streaming_cam_target_prim_path: str | None = None
    """Target prim for the auto-created streaming camera (ignored when
    :attr:`streaming_sensor_prim_path` is set).

    When ``None`` (the default), the visualizer adopts the first scene camera
    sensor it discovers dynamically at initialization time.  If no scene camera
    exists the streaming panel remains empty.  Set this explicitly (e.g.
    ``"/World/envs/*/Robot"``) only when you need an auto-created follow-camera
    and no suitable scene camera is present.
    """

    streaming_cam_eye: tuple[float, float, float] = (4.0, -4.0, 3.0)
    """Eye offset [m] for the auto-created streaming camera relative to the target prim."""

    streaming_cam_renderer_cfg: RendererCfg | None = None
    """Renderer for the auto-created streaming camera.

    Concrete visualizer configs declare their default renderer configuration.
    Its ``class_type`` selects the implementation, including custom renderers.
    Ignored when :attr:`streaming_sensor_prim_path` is set.
    """

    # Shared settings
    streaming_envs: int | list[int] = 32
    """Environments to capture.

    * ``int`` — sample this many envs once at initialization (from all visible envs).
    * ``list[int]`` — capture exactly these env indices.
    """

    streaming_gt_types: tuple[str, ...] = ("rgb",)
    """GT data types displayed left-to-right per environment row.

    Valid values: ``"rgb"``, ``"depth"``, ``"segmentation"``, ``"normals"``.
    Validated against :data:`~isaaclab.envs.utils.camera_colorizer.SUPPORTED_GT_TYPES`
    at initialization time (only when :attr:`streaming_view` is ``True``).
    """

    streaming_depth_min: float = 0.1
    """Near-clip for the turbo depth colormap [m].  Used when ``"depth"`` is in
    :attr:`streaming_gt_types`."""

    streaming_depth_max: float = 10.0
    """Far-clip for the turbo depth colormap [m].  Used when ``"depth"`` is in
    :attr:`streaming_gt_types`."""

    # Partial visualization settings
    max_visible_envs: int | None = None
    """Upper bound on how many envs are shown.

    * If visible_env_indices is not None, then this field will apply also
      to the explicit env indices set to the visible_env_indices.
    """

    visible_env_indices: list[int] | None = None
    """env indices to visualize in order (out-of-range indices are dropped)."""

    randomly_sample_visible_envs: bool = True
    """If ``max_visible_envs`` is provided, when enabled, selected visible envs are randomly sampled.
       If disabled, the first ``max_visible_envs`` envs are selected.

    * Note: ``visible_env_indices`` overrides this field.
    """

    # Visualization Markers
    enable_markers: bool = True
    """Enable visualization markers (debug drawing)."""

    # Live Plots
    enable_live_plots: bool = True
    """Stream per-step scalar data (manager terms, episode reward, episode length) into the visualizer.

    Plot windows start hidden or collapsed by default and can be toggled open at runtime.
    Set to ``False`` to disable live plots entirely and avoid any collection overhead.
    """

    live_plots_update_interval: int = 5
    """Collect and push live plot data every ``N`` simulation steps (default: every 5 steps)."""

    # Internal
    visualizer_type: str | None = None
    """Type identifier (e.g., 'newton', 'rerun', 'viser', 'kit'). Must be overridden by subclasses."""

    # Deprecated aliases kept for one-release compatibility. Remove in the next major release.
    tiled_cam_view: bool | None = None
    """Deprecated. Use :attr:`streaming_view` instead."""

    tiled_cam_num: int | None = None
    """Deprecated. Use :attr:`streaming_envs` (int) instead."""

    tiled_cam_env_indices: list[int] | None = None
    """Deprecated. Use :attr:`streaming_envs` (list[int]) instead."""

    tiled_cam_prim_path: str | None = None
    """Deprecated. Use :attr:`streaming_sensor_prim_path` instead."""

    tiled_cam_eye: tuple[float, float, float] | None = None
    """Deprecated. Use :attr:`streaming_cam_eye` instead."""

    tiled_cam_target_prim_path: str | None = None
    """Deprecated. Use :attr:`streaming_cam_target_prim_path` instead."""

    def __post_init__(self) -> None:
        import warnings

        if self.background_color is not None:
            if len(self.background_color) != 3 or any(not 0.0 <= value <= 1.0 for value in self.background_color):
                raise ValueError("background_color must contain three normalized RGB values in [0, 1].")
            self.background_color = tuple(float(value) for value in self.background_color)

        _simple = [
            ("tiled_cam_view", "streaming_view"),
            ("tiled_cam_prim_path", "streaming_sensor_prim_path"),
            ("tiled_cam_eye", "streaming_cam_eye"),
            ("tiled_cam_target_prim_path", "streaming_cam_target_prim_path"),
        ]
        for old, new in _simple:
            val = getattr(self, old)
            if val is not None:
                warnings.warn(f"{old!r} is deprecated; use {new!r} instead.", DeprecationWarning, stacklevel=3)
                setattr(self, new, val)
                setattr(self, old, None)
        # tiled_cam_env_indices takes priority over tiled_cam_num
        env_indices = getattr(self, "tiled_cam_env_indices")
        if env_indices is not None:
            warnings.warn(
                "'tiled_cam_env_indices' is deprecated; use 'streaming_envs' instead.",
                DeprecationWarning,
                stacklevel=3,
            )
            self.streaming_envs = env_indices
            self.tiled_cam_env_indices = None
            self.tiled_cam_num = None
        else:
            num = getattr(self, "tiled_cam_num")
            if num is not None:
                warnings.warn(
                    "'tiled_cam_num' is deprecated; use 'streaming_envs' instead.",
                    DeprecationWarning,
                    stacklevel=3,
                )

警告

Newton RTX（OVRTX）是不依赖 Kit 的渲染器，不能与 Kit（ presets=isaacsim_physx ）在同一进程中使用。 presets=ovphysx 本身也不依赖 Kit，可以与 Newton RTX 配合使用。请将 --viz newton_rtx 与 presets=newton_mjwarp,ovrtx 或 presets=ovphysx,ovrtx 搭配，或者改用 --viz newton_gl 、 --viz viser 、 --viz rerun ；也可以在兼容 Kit 的物理后端下使用 --viz kit 。

与 Viser 类似， Rerun 将仿真状态传输到本地 Web 服务器，支持远程观察、时间线回放和录制为 .rrd 文件。

Rerun 可视化器中的 Isaac-Reorient-Cube-Shadow-Direct
各 Shadow Hand 调整立方体朝向，使其与目标位姿一致

该可视化器的特有功能：

  • 在时间线上拖动定位，并回放 .rrd 录制文件

  • ImGui 侧栏中的 Pause Rendering （暂停渲染）和 Reset Episode （重置回合）控件

备注

在实时查看仿真或训练过程时，Rerun 界面原生的时间线播放/暂停控件不起作用。这些控件默认隐藏，但仍可通过 Rerun 的停靠面板界面显示；即使显示出来，点击也不会生效。请使用 Isaac Lab 自身的 Pause Rendering （暂停渲染）和 Reset Episode （重置回合）控件。时间线控件仅在回放已保存的 .rrd 文件时有效。

相机流视图#

相机流视图是一种实时监控和调试工具，将多个环境的相机真值帧（RGB、深度、分割或表面法线）组合到同一个面板中。图像帧可来自场景相机传感器，也可来自可视化器创建的跟随相机。多个可视化器可以显示同一个数据源，各自选择不同的平铺图块。

Galbot 立方体堆叠环境的交互视图

显示 Galbot 腕部相机平铺画面的串流视图

可以为运动中的机器人创建跟随相机，也可以选择已有视角，例如 Galbot 任务的腕部相机和机器人第一人称相机。Kit、Newton GL、Rerun 和 Viser 可视化器支持该视图；Newton RTX 目前不显示此面板，仍处于实验阶段。Kit 会打开独立的 Streaming View 视口，可与默认视口并排监控；Newton GL 则在 HUD 中增加 Streaming View 区域，提供 Hide / Open 开关和数据源下拉框。

VisualizerCfg 选项、显示数据源、故障排查和分步示例见 在可视化器中显示相机流视图 。

可视化标记#

可视化标记通过 VisualizationMarkers 在场景上绘制调试用几何图形。

AnymalD 机器人上表示目标速度和基座速度的大型绿色、蓝色箭头标记

Franka 机械臂关节上的箭头标记，以及立方体上的接触传感器标记

创建和配置自定义标记的方法见 创建可视化标记 。

可视化标记分为两类：

内置标记类型：

  • 传感器标记：接触/无接触球体、射线投射器命中点、可变形物体的运动学目标，以及视觉触觉接触点

  • 坐标系标记：带有连接线的坐标系

  • 彩色箭头（红、蓝、绿）：表示方向和速度

  • 目标形状：长方体、球体，以及具有多种状态的位置目标标记

  • 质心标记

在 Newton GL 可视化器的 HUD 中，当前未启用的内置标记类型会显示为灰色。

自定义标记：

  • 由各任务和 MDP 项定义，通过实例化各自的 VisualizationMarkersCfg 创建

  • 示例：AnymalD 的速度指令以此方式绘制绿色和蓝色的速度箭头

  • 示例：Isaac-Reorient-Cube-Allegro 任务定义自己的目标标记（DexCube 资产），用于显示立方体的目标姿态

备注

Kit、Newton GL、Rerun 和 Viser 支持可视化标记；Newton RTX（实验性）暂不支持。

实时曲线#

实时曲线将每一步的标量数据传输到可视化器中。

Newton GL 可视化器，打开了三个曲线图

Viser 可视化器，打开了一个曲线图

实时曲线窗口默认隐藏或折叠，Rerun 除外；在 Rerun 中，可通过点击“眼睛”图标折叠实时曲线。Kit、Newton GL、Rerun 和 Viser 支持此功能；Newton RTX（实验性）暂不支持。

绘制的数据： 每回合的总奖励和回合长度，以及基于管理器的环境中所有已启用的管理器项（例如 joint_pos ）。

视频录制#

视频录制可以采集任意可视化器视图的画面，包括交互视图和相机流视图，也支持采集渲染器生成的传感器数据。

Kit 可视化器平铺串流

包含真值传感器视图的录像片段

在命令行中传入 --video 可快速录制视频；也可以配置多个 VideoRecorderCfg 条目，同时录制多个数据源。未配置录制器时，--viz 决定 --video 录制哪个可视化器：

命令行参数

录制来源

--video

已配置的第一个可视化器，优先选择支持帧捕获的可视化器；未配置时使用无界面 Kit 可视化器

--video --viz newton_rtx

选定的 newton_rtx 窗口

--video --viz newton_gl,viser

同时运行两个可视化器，录制其中支持帧捕获的 newton_gl 窗口

--video --viz viser

报错，因为 Viser 没有本地帧捕获 API

Kit、Newton GL 和 Newton RTX 可视化器支持录制；基于网络的 Viser 和 Rerun 可视化器不支持。也可以使用 VideoRecorderCfg(source="sensor:<name>") 录制场景传感器。

完整指南和教程见 录制视频 。

使用方法#

常用示例#

无界面训练并录制视频

不打开窗口，将 Newton GL 或 Kit 可视化器保持运行，作为视频片段的采集来源：

uv run isaaclab train --rl_library rsl_rl --task Isaac-Cartpole \
    --viz newton_gl --headless --video

./isaaclab.sh train --rl_library rsl_rl --task Isaac-Cartpole \
    --viz newton_gl --headless --video

片段长度、录制间隔和多数据源选项见 录制视频 。

组合使用交互视图和无界面录制来源

同时配置 Kit 和无界面 Newton GL 可视化器，并在 VideoRecorderCfg 中选择 Newton GL，即可用 Kit 实时查看训练，同时从独立的 Newton GL 视角录制。配置方法见 从独立相机视角录制 。

跟随移动的机器人（Kit）

将 Kit 相机锁定到移动的资产上，无需每一步自行更新 eye / lookat ：

from isaaclab_visualizers.kit import KitVisualizerCfg

sim_cfg.visualizer_cfgs = [
    KitVisualizerCfg(
        origin_type="asset",
        origin_track_path="robot",  # or "robot/panda_hand" to track a specific body
        eye=(4.0, 4.0, 2.0),  # offset from the tracked asset
    )
]

与远程协作者共享实时画面

Viser 可以为正在运行的会话生成公开分享链接，方便远程协作，无需共享屏幕：

from isaaclab_visualizers.viser import ViserVisualizerCfg

sim_cfg.visualizer_cfgs = [ViserVisualizerCfg(share=True, open_browser=True)]

启动时会在日志中输出分享链接。Rerun 没有对应的配置字段，但其原生界面中提供了分享按钮。

配置解析规则#

可视化器由 --viz （以逗号分隔，例如 --viz kit,newton_gl ）或代码中的 SimulationCfg.visualizer_cfgs 决定。不传入 --viz 时使用配置值； --viz none 始终禁用所有可视化器，无论配置如何。

在 --viz kit 或 --viz newton_gl 的基础上加入 --headless ，可使该可视化器保持运行而不显示窗口。例如，在没有显示设备的机器上，将其作为 --video 的录制来源。

如需在代码中配置可视化器，将 VisualizerCfg 实例传给 SimulationCfg ：

from isaaclab.sim import SimulationCfg
from isaaclab_visualizers.kit import KitVisualizerCfg
from isaaclab_visualizers.newton import NewtonGLVisualizerCfg

sim_cfg = SimulationCfg(
    visualizer_cfgs=[
        KitVisualizerCfg(eye=(0.0, 0.0, 20.0)),
        NewtonGLVisualizerCfg(eye=(5.0, 5.0, 5.0), show_joints=True),
    ]
)

场景背景#

Kit 默认使用 VisualizerCfg.background_color 指定的纯天蓝色背景。Newton 可视化器将这一默认值改为 None，使 Newton GL 保留其程序化天空，Newton RTX 保留其原生背景。对于任何可视化器，将 background_color 设为 None 会保留后端的原生背景；也可以设置归一化 RGB 颜色，覆盖显示的背景色。场景灯光仍会照亮物体并参与反射：

from isaaclab.visualizers import VisualizerCfg

env_cfg.sim.default_visualizer_cfg = VisualizerCfg(background_color=(0.1, 0.2, 0.3))

各可视化器的光照差异

各后端的光照方式不同，因此同一环境在不同可视化器中可能呈现明显不同的效果。Kit 渲染场景中实际编写的 USD 灯光。Newton GL 使用固定的天空渐变和单个方向光颜色（ sky_upper_color 、 sky_lower_color 、 light_color ），不受场景 USD 灯光影响。Newton RTX 仅支持 3 种光照环境预设（ rtx_environment ： "default" 、 "studio" 、 "none" ），不使用场景中编写的 USD 灯光。Viser 只使用单个环境光，没有方向主光，因此场景通常比其他后端更暗、更缺乏层次。Rerun 使用查看器内置的固定着色方式，不由场景灯光驱动。

Kit：与 ovphysx / ovrtx 预设不兼容

--viz kit 不能在同一进程中与 presets=ovphysx 或 presets=ovrtx 配合使用。请在这些预设下使用 --viz newton_gl 、 --viz rerun 或 --viz viser ，也可以省略 --viz 进行无界面运行。

Newton RTX：与 Kit 不兼容

如果启用的物理后端是 isaacsim_physx （即 presets=isaacsim_physx ）， --viz newton_rtx 会在启动时抛出 RuntimeError ，因为 OVRTX 不依赖 Kit，不能与 Kit 共用进程。 presets=ovphysx 本身不依赖 Kit，仍受支持。请将 --viz newton_rtx 与 presets=newton_mjwarp,ovrtx 或 presets=ovphysx,ovrtx 配合使用，或者改用 --viz newton_gl 、 --viz viser 、 --viz rerun ；也可以在兼容 Kit 的物理后端下使用 --viz kit 。

Rerun：大量环境下的性能

环境较多时，Rerun 网页查看器可能变慢或崩溃。可通过 --num_envs 降低负载：

uv run isaaclab train --rl_library rsl_rl --task Isaac-Cartpole --viz rerun --num_envs 512

./isaaclab.sh train --rl_library rsl_rl --task Isaac-Cartpole --viz rerun --num_envs 512

Rerun：首批数据加载前页面为空白

Rerun 浏览器标签页打开后会先显示空白，几秒后才出现场景和实时曲线（视场景大小而定，最长约 10 秒）。这是正常现象：网页查看器需要连接本地 Rerun 服务器并接收首批日志数据。但在此期间页面没有加载提示，看起来可能像是卡住了。无需操作，等待第一帧到达即可。

Newton GL：CUDA/OpenGL 互操作警告

在某些配置下，Newton GL 可视化器会输出关于 CUDA/OpenGL 互操作的警告：

Warning: Could not get MSAA config, falling back to non-AA.
Warp CUDA error 999: unknown error (in function wp_cuda_graphics_register_gl_buffer)
Warp UserWarning: Could not register GL buffer …

可视化器仍能正常工作，但会回退到 CPU 拷贝操作，性能会有所下降。

Newton GL：OpenGL 上下文创建失败

如果 pyglet 提示 glCreateShader 未导出，或需要 OpenGL 2.0，说明进程运行时没有 GPU 支持的显示上下文（例如服务会话，或未启用 GPU 加速的远程桌面）。请在具有 GPU 支持的交互式显示会话中运行，也可以省略 --viz newton_gl ，改为无界面运行。

Newton GL：Spark + conda

通过 conda 安装的 X11 库可能在 Spark 上与 pyglet 冲突，产生如下错误：

pyglet.window.xlib.XlibException: Could not create UTF8 text property

移除存在冲突的 conda 包，改用系统库：

conda remove --force xorg-libx11 libxcb
