快速入门#

本页介绍如何从刚克隆的仓库开始，训练、运行并查看你的第一个任务。前置要求见 系统要求 。所有命令均在 Isaac Lab 仓库根目录下通过 uv run 执行， uv 会自动创建并管理项目环境。

安装并运行第一个任务#

安装 uv ，克隆 Isaac Lab 并进入仓库目录：

curl -LsSf https://astral.sh/uv/install.sh | sh
git clone https://github.com/isaac-sim/IsaacLab.git
cd IsaacLab

使用 Newton MJWarp 物理后端训练 Cartpole，并打开 Newton 可视化器：

uv run isaaclab train --task Isaac-Cartpole --num_envs 16 --viz newton

训练输出（包括检查点）保存在 logs/ 目录下。在命令后添加 --help ，即可查看可用参数：

uv run isaaclab train --help

配置编辑器（可选）#

要在 VS Code 或 Cursor 中使用导入补全和调试功能，请在仓库根目录下生成适用于当前机器的编辑器配置：

uv run isaaclab --editor

如果使用 isaacsim 可选依赖组，请在命令中包含它，以便查找 Isaac Sim 扩展：

uv run --extra isaacsim isaaclab --editor

VS Code 使用 Pylance；Cursor 用户应安装 basedpyright。完整的编辑器配置和故障排查说明见 编辑器配置 。

提示

uv run 会自动安装核心依赖。要使用可选集成，请在 isaaclab 前添加 --extra <name> 。多个可选依赖组可以用逗号分隔。例如：

uv run --extra ovphysx isaaclab train --task Isaac-Cartpole physics=ovphysx

可选依赖组负责安装所需功能，任务选择器则决定任务使用哪些功能。例如， --extra ovphysx 安装 OV PhysX 集成，而 physics=ovphysx 为任务选用该后端。你可以按需组合多个依赖组。 --extra all 会安装预先选定的 ov 、 rl-games 、 sb3 、 skrl 、 rsl-rl 、 rerun 和 viser 依赖组，但不包含 Isaac Sim、独立导入器，以及 rlinf 、 mimic 、 teleop 、 tetrahedralization 、 video 、 leapp 和 torchrl 等专用依赖组；这些需要显式添加。完整列表见 可选依赖组 。

选择强化学习库#

在 train 或 play 命令中通过 --rl_library 选择强化学习框架。省略该参数时，Isaac Lab 使用任务注册的默认框架。大多数核心任务默认使用 rsl_rl ；它已包含在标准 uv run 环境中，适合作为 GPU 训练的入门选择。

rsl_rl

快速 GPU 训练与策略蒸馏

uv run isaaclab train --rl_library rsl_rl ...

rl_games

PPO、SAC 和 A2C 工作流程

uv run --extra rl-games isaaclab train --rl_library rl_games ...

skrl

支持多种算法，兼容 PyTorch 和 JAX

uv run --extra skrl isaaclab train --rl_library skrl ...

sb3

Stable-Baselines3 及以 CPU 为主的实验

uv run --extra sb3 isaaclab train --rl_library sb3 ...

rlinf

VLA 模型微调

uv run --extra rlinf isaaclab train --rl_library rlinf ...

torchrl

使用 PyTorch 原生强化学习组件运行 PPO

uv run --extra torchrl isaaclab train --rl_library torchrl ...

各强化学习库支持的算法、任务和工作流程有所不同。详细比较见 选择强化学习库 。

五个常用命令#

所有任务命令都接受 --task <task_name> 参数。首先列出已注册的任务：

uv run python scripts/environments/list_envs.py

命令

用途

示例

train

使用强化学习库训练策略。

uv run isaaclab train --task Isaac-Cartpole

play

从检查点运行已训练的策略。

uv run isaaclab play --task Isaac-Cartpole --checkpoint latest

zero_agent

使用零动作运行任务，确认任务能够正常启动。

uv run isaaclab zero_agent --task Isaac-Cartpole --viz newton

random_agent

使用随机动作运行任务，快速检查交互是否正常。

uv run isaaclab random_agent --task Isaac-Cartpole --viz newton

benchmark

测量环境、训练、策略运行或启动性能。

uv run isaaclab benchmark runtime --task Isaac-Cartpole

所有受支持的强化学习库都通过 --checkpoint 选择用于策略运行的检查点。完整的训练和策略运行说明见 强化学习 。

选择后端#

Isaac Lab 支持多种物理和渲染后端。通过 physics=<backend> 选择物理实现；对于相机任务，通过 renderer=<backend> 选择渲染器。可用后端取决于任务配置。通过任务的帮助信息查看它支持的选择器：

uv run isaaclab train --task Isaac-Cartpole --help

选择器

后端

所需可选依赖组

physics=newton_mjwarp

使用 MuJoCo-Warp 求解器的 Newton 后端。

None

physics=newton_kamino

使用 Kamino 求解器的 Newton 后端。该后端处于测试阶段，目前仅支持部分任务。

None

physics=ovphysx

OV PhysX 后端。

ov 或 ovphysx

physics=isaacsim_physx

Isaac Sim PhysX 后端。

isaacsim

renderer=newton_renderer

Newton Warp 渲染器。

None

renderer=ovrtx

OV RTX 渲染器。

ov 或 ovrtx

renderer=isaacsim_rtx

Isaac Sim RTX 渲染器。

isaacsim

renderer=rtx

自动选择 RTX 渲染器。

isaacsim 或 ovrtx

使用 presets=<name> 应用任务专用的配置预设。例如：

uv run isaaclab train --task Isaac-Cartpole-Camera physics=newton_mjwarp renderer=newton_renderer presets=rgb

后端和预设的选择方法见 后端与预设 ；任意配置项的覆盖方法见 Hydra 配置系统 。

查看任务的可视化画面#

训练或运行策略时，使用 --viz （或 --visualizer ）选择一个或多个可视化器。使用多个可视化器时，以逗号分隔名称，中间不要加空格，例如 --viz newton,rerun 。

选项

用途

所需可选依赖组

--viz newton

打开 Newton 可视化器。

None

--viz rerun

将任务画面流式传输到 Rerun 可视化器。

rerun

--viz viser

打开基于网页的 Viser 可视化器，适用于远程连接。

viser

--viz kit

如果当前环境支持 Kit，则打开 Kit 可视化器。

isaacsim

省略 --viz 或使用 --viz none

不启用可视化器。

None

例如，同时在 Newton 和 Rerun 中查看同一个任务：

uv run --extra rerun isaaclab random_agent --task Isaac-Cartpole \
   physics=newton_mjwarp --viz newton,rerun

可视化器的安装与配置方法见 可视化 。

运行已训练的策略#

首先训练 Cartpole，生成检查点：

uv run isaaclab train --task Isaac-Cartpole

然后在 Newton 可视化器中运行最新检查点：

uv run isaaclab play --task Isaac-Cartpole --checkpoint latest --viz newton

通过以下选项之一选择检查点：

选项

加载内容

--checkpoint <path>

指定本地路径的检查点文件。部分强化学习库也接受训练运行目录。

--checkpoint best

各库对应的最佳或最终检查点。如果没有单独保存最佳或最终检查点，则回退到 latest 。

--checkpoint latest

最近一次兼容训练运行中，训练步数最多的检查点。

--checkpoint pretrained

由 Isaac Lab 托管的预训练检查点，仅适用于受支持的任务。

对任务进行性能测试#

isaaclab benchmark 的第一个参数是工作流程名称。可以先使用 runtime ，测量不运行策略时环境的步进吞吐量：

uv run isaaclab benchmark runtime --task Isaac-Cartpole

工作流程

测量内容

runtime

施加随机动作时的环境步进吞吐量（不运行策略）。

startup

启动、导入、配置、场景创建和首次步进的延迟。

training

端到端学习吞吐量，需要指定 --rl_library 。

play

已训练策略的轨迹采样吞吐量，需要指定 --rl_library 和 --checkpoint 。

_multigpu

在 startup 、 runtime 或 training 后添加 _multigpu 后缀，即可在多个 GPU 上运行，例如 runtime_multigpu 。

性能测试基础知识见 性能测试 ；多 GPU 训练与性能测试见 多 GPU 和多节点训练 。
